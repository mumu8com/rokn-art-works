# ركن للأعمال الفنية

موقع عربي باتجاه RTL لعرض المنتجات الفنية حسب الطلب، مع استوديو معاينة للمنتج ولوحة إدارة محمية بتسجيل دخول من جهة الخادم.

## التشغيل محليًا

- Node.js 20 أو أحدث
- `npm install`
- `npm run dev` للتطوير
- `npm run build` لاختبار بناء الإنتاج
- `npm start` لتشغيل نسخة الإنتاج

## إعداد دخول المدير على Render

من لوحة خدمة Render، افتح **Environment** وأضف المتغيرات التالية. لا تضعها في ملفات GitHub:

- `ADMIN_EMAIL`: البريد الإلكتروني الذي سيستخدمه المدير لتسجيل الدخول.
- `ADMIN_PASSWORD`: كلمة مرور قوية وفريدة للمدير.
- `ADMIN_SESSION_SECRET`: سر عشوائي طويل لا يقل عن 32 حرفًا، ويُفضّل 64 حرفًا أو أكثر.

بعد حفظ المتغيرات، أعد نشر الخدمة. صفحة الدخول: `/admin/login`، ولوحة الإدارة: `/admin`. جلسة المدير تستخدم ملف تعريف ارتباط HttpOnly موقّعًا وتنتهي بعد 8 ساعات.

## ما تتضمنه النسخة الحالية

- واجهة متجر عربية متجاوبة وتصنيفات عرض للمنتجات والخدمات.
- استوديو معاينة أولي لتعديل النصوص والألوان ونوع المنتج والخامة والمقاس والكمية.
- تنزيل معاينة بصيغة SVG وتجهيز رسالة بريد لطلب عرض سعر.
- لوحة إدارة عربية مع أقسام للمنتجات والتصميمات والطلبات والعملاء وعروض الأسعار والإعدادات.
- تسجيل دخول مدير مع التحقق من الجلسة على الخادم.

## حدود يجب معرفتها قبل التشغيل التجاري

- قائمة المنتجات التي تعدّلها لوحة الإدارة تحفظ في المتصفح الحالي فقط، وليست قاعدة بيانات مشتركة أو دائمة.
- أقسام الطلبات والعملاء وعروض الأسعار هي واجهات تأسيسية ولم تُربط بعد بمخزن بيانات فعلي.
- نموذج التصميم هو معاينة ثنائية الأبعاد وليس ملف تصنيع نهائيًا أو محرر CAD/3D.
- لا توجد بوابة دفع أو عملية شراء إلكترونية مكتملة. يجب ربط قاعدة بيانات دائمة وتخزين ملفات آمن وإجراءات الطلبات قبل استقبال طلبات فعلية على نطاق تجاري.

لا تضع بيانات العملاء أو كلمات المرور في مستودع Git أو داخل الشيفرة المصدرية.
