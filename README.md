# ركن للأعمال الفنية

واجهة أولية لموقع عربي لعرض الدروع والهدايا الفنية، مبنية باستخدام Next.js وReact.

## التشغيل

- Node.js 20 أو أحدث
- `npm install`
- `npm run build`
- `npm start`

هذه نسخة واجهة أولية فقط. لا تتضمن حاليًا تسجيل دخول، لوحة إدارة آمنة، تخزين طلبات، تصدير SVG فعليًا، أو بوابة دفع مفعّلة. يجب تنفيذ واختبار هذه الميزات قبل استقبال طلبات أو مدفوعات حقيقية.
